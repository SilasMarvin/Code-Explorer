# The way up a journey: the start's callers in a row above its bar in the panel. Up
# from the start sets the first of them aside, left and right walk the row, down comes
# back to the start, and Enter opens the caller's journey, Back returning past the row;
# a click on a caller's bar sets it aside too, and Shift-click on a caller opens its journey. `i` with nothing
# off the journey calling in leaves itself off. The top bar says which module is
# expanded. Search lists a function whose own name holds the query before one whose
# module's does.
key /
type order
key down
key enter
expect selection Store::insert_order

click orders::place
key enter
expect start orders::place
snap journey

key up
expect aside POST /users/{id}/orders
expect cursor orders::place
expect nothing-moved
expect check panel-agrees
snap up into the callers

key right
expect aside POST /orders/{id}/reorder
key right
expect aside POST /orders/{id}/reorder
key down
expect aside none
expect cursor orders::place
expect nothing-moved
snap down to the start

bar POST /orders/{id}/reorder
expect aside POST /orders/{id}/reorder
expect nothing-moved
key enter
expect start POST /orders/{id}/reorder
key backspace
expect start orders::place

# Moving along the row makes no place of its own: Back from the caller's journey
# returns to the start's, and once more to before it.
key up
key right
key enter
expect start POST /orders/{id}/reorder
key backspace
expect start orders::place
expect aside none
key backspace
expect mode browse
key shift+backspace
expect start orders::place

shift+click POST /users/{id}/orders
expect start POST /users/{id}/orders
key backspace
expect start orders::place

bar 3
expect cursor pricing::quote
snap on quote

key i
expect outside_callers false
expect nothing-moved
snap no calls in from outside

key x
expect expanded pricing
snap inside pricing
